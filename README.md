## 📌 Description & Overview

Contrôle en boucle fermée pour la stabilisation d'une plateforme mobile 3D avec régulation PID interactive et visualisation de l'asservissement.

This project is an interactive engineering module built by **DJIDEL Abdelali Rayan** (Systems & Automation Engineer).
